PoB 한글 패처 (PoB-KR-Patcher)
================================

Path of Building Community Fork 를 인게임 한국어 명칭으로 보여 주는 프로그램입니다.
설치 파일 없이 이 실행 파일 하나로 동작합니다.

■ 사용법

 1. PoB-KR-Patcher.exe 를 실행합니다. (아무 폴더에 두어도 됩니다)
 2. [한글 패치 적용 / 업데이트] 를 누릅니다.
    - Path of Building 폴더는 자동으로 찾습니다.
    - 찾지 못하면 폴더 선택 창이 열립니다.
      Modules 폴더가 들어 있는 Path of Building 폴더를 선택하세요.
    - 패치가 끝나면 "Path of Building (한글)" 바로가기가
      PoB 폴더 안과 시작 메뉴에 생깁니다.
 3. "Path of Building (한글)" 아이콘으로 실행합니다.
    (윈도우 키를 누르고 Path of Building 을 검색해도 됩니다)
    게임 안에서 F2 키를 누르면 한글/영문 표시가 바로 바뀝니다.

■ 바로가기

 - 바로가기는 패치한 PoB 폴더 안과 시작 메뉴에 만들어집니다.
   사람마다 PoB 를 두는 위치가 달라서 바탕화면은 기본으로 만들지 않습니다.
   바탕화면에도 만들려면 창의 [바탕화면에도 바로가기 만들기] 를 체크하세요.
 - 이 아이콘으로 실행하면 매번 최신 한글 패치를 확인·적용한 뒤 PoB 가 열립니다.
   (창은 뜨지 않고, 1초 넘게 걸릴 때만 작은 알림이 잠깐 보입니다)

■ 자동 업데이트

 - 바로가기로 실행할 때: 새 버전 확인(최대 3~4초) → 내려받기 → 적용 → PoB 실행.
   인터넷이 느리거나 없으면 기다리지 않고 지금 있는 데이터로 실행합니다.
 - Path of Building.exe 를 직접 실행할 때: 6시간에 한 번, 뒤에서 조용히
   최신 패치를 미리 받아 둡니다. (PoB 로딩을 막지 않습니다.
   이때 콘솔 창이 아주 잠깐 깜빡일 수 있습니다)
   받아 둔 패치는 다음 PoB 실행 때 자동으로 반영됩니다.
 - PoB 를 업데이트해서 Modules\Main.lua 가 영문 원본으로 돌아가면
   다음 실행 때 한글 로더를 자동으로 다시 넣습니다.

■ 주의

 - Path of Building 이 실행 중이면 패치할 수 없습니다. 창을 닫고 다시 실행하세요.
 - 원본 Modules\Main.lua 는 KR\_설치기록\Main.lua.orig 에 백업됩니다.

■ 영문으로 되돌리기

  [영문 원본으로 복구] 를 누르면 Main.lua 가 원래대로 돌아가고 KR 폴더가 삭제됩니다.

■ 계산값은 그대로

  이 프로그램은 화면에 표시되는 글자만 한글로 바꿉니다.
  DPS, Life 등 계산 결과는 영문판 Path of Building 과 완전히 같습니다.
