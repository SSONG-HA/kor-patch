PoB 한글 패처 (PoB-KR-Patcher)
================================

Path of Building 의 화면 글자를 인게임 한국어 명칭으로 보여 주는 프로그램입니다.
한 실행 파일로 **PoE1(PoB Community Fork)** 과 **PoE2(Path of Building PoE2)** 를
각각 패치할 수 있습니다. 설치 과정 없이 이 파일 하나로 동작합니다.

■ 준비

 - PoE1 : Path of Building (Community Fork) 이 설치되어 있어야 합니다.
 - PoE2 : Path of Building PoE2 가 설치되어 있어야 합니다.

■ 사용법

 1. PoB-KR-Patcher.exe 를 실행합니다. (아무 폴더에 두어도 됩니다)
 2. 창에 두 칸이 있습니다.
      · 위 : PoE1 — Path of Building
      · 아래 : PoE2 — Path of Building PoE2
 3. 원하는 칸의 [폴더 선택...] 으로 설치 폴더를 지정할 수 있습니다.
    (Modules 폴더가 들어 있는 폴더입니다. 보통은 자동으로 찾습니다)
 4. [PoE1 패치 및 실행] 또는 [PoE2 패치 및 실행] 을 누르면
    최신 한글 데이터를 확인·적용한 뒤 해당 PoB 가 열립니다.
    - 데이터만 갱신하려면 [패치 적용] 만 눌러도 됩니다.
 5. 게임 안에서 F2 키를 누르면 한글/영문 표시가 바로 바뀝니다.

■ 데이터가 들어가는 곳

 - PoE1 : <Path of Building>\KR
 - PoE2 : <Path of Building PoE2>\KR2
 두 폴더는 서로 섞이지 않으며, 원본 Modules\Main.lua 는 각 폴더의
 _설치기록\Main.lua.orig 로 백업됩니다. [영문 원본으로 복구] 를 누르면 되돌아갑니다.

■ 바로가기

 - 패치를 마치면 각 PoB 폴더 안과 시작 메뉴에 바로가기가 생깁니다.
      · Path of Building (한글)
      · Path of Building PoE2 (한글)
 - 이 아이콘으로 실행하면 매번 최신 한글 패치를 확인·적용한 뒤 PoB 가 열립니다.
   (창은 뜨지 않고, 1초 넘게 걸릴 때만 작은 알림이 잠깐 보입니다)
 - 바탕화면에도 만들려면 창의 [바탕화면에도 바로가기 만들기] 를 체크하세요.

■ 자동 업데이트

 - 바로가기로 실행할 때: 새 버전 확인(최대 3~4초) → 내려받기 → 적용 → PoB 실행.
   인터넷이 느리거나 없으면 기다리지 않고 지금 있는 데이터로 실행합니다.
 - PoB 본체를 직접 실행할 때: 6시간에 한 번, 뒤에서 조용히 최신 패치를
   미리 받아 둡니다. 받아 둔 패치는 다음 PoB 실행 때 자동으로 반영됩니다.
 - PoB 를 업데이트해서 Modules\Main.lua 가 영문 원본으로 돌아가면
   다음 실행 때 한글 로더를 자동으로 다시 넣습니다.

■ 주의

 - PoB 가 실행 중이면 파일이 잠겨 패치가 실패할 수 있습니다. 창을 닫고 다시 실행하세요.
 - 한글 패처는 화면 표시 계층만 바꿉니다. DPS·생명력 등 계산값은 영문판과 완전히 같습니다.
 - 게임이 업데이트되어 데이터가 바뀌면 새 데이터가 올라올 때까지 일부 문구가 영문으로 보일 수 있습니다.

■ 알려진 한계

 - 젬 툴팁의 "능력치 설명" 긴 문장(예: "Deals 2343 to 3453 Chaos Damage")은
   게임 데이터의 문장 틀을 옮겨야 해서 아직 영문으로 표시됩니다.
 - 플레이어가 직접 지은 희귀 아이템 이름은 번역하지 않습니다(그대로 표시).
